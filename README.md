# Luxury Homes: Microsite editor prototype

Clickable prototype, built from the final Figma design (CRM Dashboard, node 14193:401588), of the **Luxury Homes** section in the ListaCRM Microsite editor (Editor › SEO Content › Luxury Homes). Demo data only.

- [index.html](index.html): open in a browser.
- [luxury-homes-editor-flow.md](luxury-homes-editor-flow.md): flow, fields, rules and open decisions.

What it shows:
- Luxury Homes is **SEO configuration only**, built on the farm areas in IDX Configuration. Listings come from the farm areas; nothing about listings is set here.
- Page content: Hero, Contact call to action and News Letter.
- Configuration: farm area, stats, Luxury Pages with Add Page, filter tabs and page cards.
- Area pages: choose an Active farm area first, then Add Area with an Area type (City, County or Community) and one place of that type, both single select. Name, H1 and URL are automatic. Content, pin (max 6), order and publish.
- A disclaimer, the farm area behind each page, and a publish checklist.

Tip: Shift-click any Upload button to attach a demo image.
