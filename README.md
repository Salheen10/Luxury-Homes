# Luxury Homes: Microsite editor prototype

Clickable prototype of the **Luxury Homes** section in the ListaCRM Microsite editor (Editor › SEO Content › Luxury Homes). Demo data only.

- [index.html](index.html): open in a browser.
- [luxury-homes-editor-flow.md](luxury-homes-editor-flow.md): flow, fields, rules and open decisions.

What it shows:
- Editable content of the /luxury-homes page (hero, areas section, about, FAQ, call to action).
- Areas: one county, city or community each, with a free-text price range, property sub types, pin (max 6) and publish.
- Live match count, sample listings, a publish checklist, and a Website / Mobile preview of the public pages.

Tip: Shift-click any Upload button to attach a demo image.
